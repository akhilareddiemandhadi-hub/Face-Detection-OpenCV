# Face Detection using OpenCV

Real-time face detection project using Python + OpenCV + Haar Cascade Classifier.

## 📌 Features
- Detects faces through webcam in real-time
- Draws rectangle around detected faces 
- Uses Haar Cascade pre-trained model
- Lightweight and fast

## 🛠️ Tech Stack
Python, OpenCV, Haar Cascade

## 🚀 How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run code: `python detect.py`
3. Press `q` to quit webcam

## 📸 Output
Detects multiple faces and shows count on screen
